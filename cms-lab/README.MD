# Simple CMS

Simple CMS is a backend web application developed using Flask,
MongoDB, PyMongo and Jinja2.

Users can create blog posts, view all posts and open individual
posts to read their complete content.

## Technologies Used

- Python
- Flask
- MongoDB
- PyMongo
- Jinja2
- HTML
- CSS

## MongoDB Configuration

Database:

cms_lab

Collection:

posts

MongoDB URL:

mongodb://127.0.0.1:27017

## Installation

Install the required Python packages:

pip install flask pymongo

## Run the Application

Make sure MongoDB is running.

Then execute:

python app.py

Open the following URL in the browser:

http://127.0.0.1:5000

## Features

- Create blog posts
- Server-side validation
- Automatic creation date
- MongoDB persistence
- Display all posts
- View individual posts
- Jinja2 server-side templates
